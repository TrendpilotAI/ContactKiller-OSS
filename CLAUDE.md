# Project Instructions for AI Agents

All repo-level agent rules live in [AGENTS.md](AGENTS.md): required `bd` ticket
tracking, the Provenance convention, install and bootstrap steps, and the
session-completion protocol. Follow it; this file intentionally adds nothing else.

Quick start: `bd prime` for workflow context, `bd ready` to find work,
`bd update <id> --claim` to claim it, `bd close <id>` to finish it.
