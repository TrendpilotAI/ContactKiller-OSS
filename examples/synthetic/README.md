# Synthetic fixtures

Every identity in this directory is fictional. Email addresses use reserved example domains and phone numbers use documented fictional ranges.

The default scenario models one person represented differently across multiple accounts:

- iCloud has a preferred name and phone;
- personal Google has a newer email;
- work Google has a legacy company record;
- a CRM labels the record as a lead; and
- WhatsApp evidence contains only a number.

Use these fixtures for adapters, normalization, provenance, replay, and UI tests. Do not replace them with exported personal records.
